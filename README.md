## 🚨 PhishGuard — AI-powered Phishing Detection & Browser Protection

PhishGuard is an AI-driven phishing detection project that provides a browser extension, a Next.js dashboard, and a Python model-backed API for scanning URLs in real time. It combines an ONNX model, heuristic feature extraction, and web analysis to surface risk scores, human-friendly reports, and remediation recommendations.

## Description
PhishGuard detects phishing websites and suspicious URLs using a combination of an ONNX model and heuristic feature extraction. It ships as a Chrome extension for real-time protection, a Next.js dashboard for scan history and recommendations, and a Python-backed API for batch or server-side scanning.

## Features
- Real-time URL scanning via a browser extension (Manifest V3).
- Dashboard (Next.js + TypeScript) to view scan history, trends, and reports.
- ONNX model inference (Node.js and Python clients supported).
- Python FastAPI service exposing GET/POST endpoints for scanning and full site analysis.
- Heuristic feature extraction (redirects, IP domain, length, shorteners, etc.).
- Recommendations and contextual guidance for mitigation (password managers, MFA, VPNs).
- CORS-enabled API for extension/frontend integration.

## Tech Stack
- Frontend: Next.js (App Router), React, TypeScript, Tailwind CSS
- Browser extension: Manifest V3, vanilla JS/CSS for popup & content scripts
- Backend/API: Python (FastAPI) — also contains a lightweight Flask alternative in requirements
- ML / Inference: ONNX Runtime (node + python), model stored at `public/model/model.onnx`
- Dev / Packaging: npm, pip, uvicorn
- Other: tldextract, validators, requests, numpy

## Installation
Prerequisites:
- Node.js 18+ and npm
- Python 3.9+ and pip

1) Clone the repo

```powershell
git clone https://github.com/badar24434/phishguard.git
cd phishguard
```

2) Install and run the Python API (server)

```powershell
cd project/server
python -m pip install -r ..\..\requirements.txt
# start local API (FastAPI + Uvicorn recommended)
python -m uvicorn api:app --host 127.0.0.1 --port 8001
```

Notes:
- The API loads an ONNX model via `PredictURL` in `project/server/feature_extraction.py`. The server expects the model to be at `project/public/model/model.onnx` relative to the repo root.

3) Install and run the Next.js frontend (dashboard + API proxy)

```powershell
cd ..\..\project
npm install
npm run dev
# frontend is available at http://localhost:3000
```

4) Load the Extension (development)
- Build the app (optional) with `npm run build`.
- In Chrome: go to `chrome://extensions`, enable Developer Mode, click "Load unpacked", and point to `project/extension`.

Environment/Configuration
- The extension and frontend expect the API at `http://localhost:8001` (see `extension/manifest.json` host_permissions). If your API runs elsewhere, update the extension `api` calls and `manifest.json` accordingly.
- Add any API keys or secrets to `project/server/.env` if your integrations (WHOIS, external services) require them.

## Usage

- To scan a URL via the Python API (GET):

```http
GET http://localhost:8001/api?url=https://example.com

Response (200):
{
  "url": "https://example.com",
  "timestamp": "2025-10-25T12:34:56.789123",
  "isPhishing": false,
  "confidence": 0.12,
  "Generated by PhishGuard AI at": "2025-10-25 12:34:56"
}
```

- To scan via POST:

```http
POST http://localhost:8001/api
Content-Type: application/json

{
  "url": "https://example.com"
}
```

- The Next.js app also exposes a server route at `/api/scan` (frontend) which proxies to the model logic in `project/lib/model.server.ts`. The extension and frontend expect responses shaped like:

```json
{
  "url": "...",
  "timestamp": "...",
  "isPhishing": true|false,
  "confidence": 0.0-1.0
}
```

Short descriptions
- `project/app` — Next.js frontend (landing page, dashboard, alerts, scanner UI).
- `project/extension` — Chrome extension (popup, background worker, content scripts).
- `project/public/model/model.onnx` — trained ONNX model used by both Node and Python runtimes.
- `project/lib/model.server.ts` — Node-side ONNX runtime initialiser & adapter.
- `project/server/api.py` — FastAPI endpoints for `/`, `/api`, and `/api/analyze`.

## API Endpoints

- GET / (root)
  - Returns service status and available endpoints.

- GET /api?url=<url>
  - Query param: `url` (required). Validates URL and returns scan result.

- POST /api
  - Body: `{ "url": "https://..." }`
  - Returns JSON scan result (see examples above).

- POST /api/analyze
  - Body: `{ "url": "https://..." }`
  - Runs deeper website analysis (uses `services.website_analyzer`), merges model prediction and returns a summary report.

Example scan response

```json
{
  "url": "https://suspicious-site.com",
  "timestamp": "2025-10-25T12:34:56.789123",
  "isPhishing": true,
  "confidence": 0.87
}
```

## Model & Data
- The repo contains an ONNX model used for URL classification at `project/public/model/model.onnx`.
- Node usage: `project/lib/model.server.ts` loads the model with `onnxruntime-node` and exposes `initModel()` and `runInference(url)`.
- Python usage: `project/server/feature_extraction.py` provides `PredictURL` which loads the same ONNX model via `onnxruntime` and produces probabilities.
- Heuristics: `FeatureExtract` includes URL heuristics (IP host, length, redirect presence, dash in domain, shorteners).

Notes about model inputs/outputs
- The Node server expects a string tensor input and reads output named `probabilities` (index 1 = phishing probability).
- The Python predictor also expects a string array and returns `isPhishing` and `confidence` (phishing probability).

# **PhishGuard**  
### **AI-Powered Phishing Detection and Security Recommendations**

PhishGuard is a comprehensive browser extension designed to detect phishing websites in real-time, provide actionable insights, and recommend security tools like password managers, secure browsing tools,MFA apps and many more to enhance online safety.

## **Features**  
- **Real-Time Phishing Detection**: Instantly flags malicious and suspicious websites using AI-powered models.  
- **Comprehensive Security Analysis**:  
  - WHOIS domain verification  
  - Geolocation mismatch analysis  
  - DNS record validation  
  - Website categorization  
- **AI-Powered Risk Assessment**: Generates clear, human-readable security reports with AI.  
- **Tool Recommendations**: Suggests trusted security tools like password managers, VPNs, and MFA apps based on detected threats.  
- **Browser Extension**: Seamless integration with real-time alerts and warnings.  
- **User Monitoring**: Tracks scan history, trends, and threat statistics for continuous security awareness.
